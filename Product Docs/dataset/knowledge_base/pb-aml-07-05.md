# Check prior alerts and case history

Review whether the customer, the account, or any involved counterparty has appeared in a prior alert or investigation. Note the disposition that was recorded and the rationale given at the time. Use this history as context for the current investigation — it does not by itself justify either escalation or closure of the current case.
