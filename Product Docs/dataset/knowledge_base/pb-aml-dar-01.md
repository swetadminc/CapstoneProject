# Identify and document a dormant account reactivation pattern

Establish the length of the dormancy period by comparing the date of the reactivating transaction against the
account's most recent prior transaction — months of complete inactivity followed by a sudden large transaction
is itself the red flag, independent of the amount alone. Compute how far the reactivating transaction deviates
from the account's historical baseline average, and note whether the funds simply arrive, or arrive and then
move on again quickly (a pass-through pattern layered onto the dormancy trigger, which is a stronger indicator
than either pattern alone). Document the account's ordinary pre-dormancy activity so a reviewer can see what
"normal" looked like for this customer before judging what changed.
