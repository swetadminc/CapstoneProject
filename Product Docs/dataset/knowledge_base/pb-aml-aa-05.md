# Documentation required before closing an amount-anomaly case

Before closing with no concern: confirm the deviation ratio was computed correctly, the source of funds is documented or plausibly explained, the customer's profile is consistent with the amount (or the inconsistency is explained), and the investigator has recorded a written rationale.
