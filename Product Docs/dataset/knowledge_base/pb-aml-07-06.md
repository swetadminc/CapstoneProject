# Review supporting documentation for legitimacy

Where the customer or the investigator has obtained supporting documents such as an invoice, a sales contract, or a purchase order, confirm the document's stated amount, dates, and named counterparty are consistent with the transaction under review. A document that is present but inconsistent with the transaction details should be recorded as Conflicting evidence.
