# Verify source of funds for the anomalous amount

Request documentation tying the specific amount to a plausible source: a sale deed, a bonus letter, an insurance settlement, or an inheritance record. Absence of documentation after a reasonable request is recorded as Missing evidence, not treated as proof of concern.
