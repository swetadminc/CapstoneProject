# Identify and document a structuring pattern

List every transaction in the cluster with its exact amount, date, and channel, and compute the total value
moved. A structuring pattern is characterized by multiple transactions each individually below a known
reporting or internal review threshold, occurring close together in time, that in aggregate would have
required additional scrutiny as a single transaction. Note whether the amounts are similar in size (a
stronger indicator) or vary widely (a weaker one), and whether the channel or counterparty changes between
transactions in a way that looks like an attempt to avoid a single large, traceable transaction.
