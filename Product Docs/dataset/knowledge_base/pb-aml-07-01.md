# Review customer KYC and profile information

Confirm the customer's KYC status is current before proceeding with the investigation. Compare the declared occupation, income, and expected activity against the customer's profile on file. Flag any mismatch between the declared profile and the observed transaction behaviour as a finding requiring explanation, not as a conclusion on its own.
