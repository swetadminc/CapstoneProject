# Verify source of funds

Request documentation supporting the declared source of funds for the flagged credit. Acceptable evidence includes an invoice, a signed contract, a sale deed, or equivalent proof tied to the transaction amount and date. If no documentation is provided after a reasonable request, record this explicitly as Missing evidence rather than assuming either legitimacy or wrongdoing.
